# 六件公共被动 · 战场实体

`relic-0.webp` 至 `relic-5.webp` 依次为青绿沙狐镜像、金橙火轮、绯红幽魂提灯、黄铜钢锚、冰蓝羽梭、紫铜蓄电战鼓。每张为 192 × 192 RGBA，使用居中锚点。羽梭的原生行进方向为右上方约 43°，旋转追踪方向时可据此设置偏移。

`master.png` 是完整的 1536 × 1024 原图。用同目录的 `rebuild.py` 导出居中对齐的 WebP 和含 32 像素小图的 `preview.jpg`。脚本中的源图及输出均使用相对位置，整个目录可移动。执行命令为 `uv run --no-project --with pillow --with numpy --with scipy python rebuild.py`。

ImageGen 母版最初保存于 `art/forge/relics/master.png`。样式参考为 `public/art/kit-3.webp`。
