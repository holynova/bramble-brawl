# 沙棘乱斗 1.3 战斗角色

本轮交付的原始无损母版保存在工程的 [masters](../masters) 目录。导出脚本使用工程内的母版，可在其他机器重建。

| 角色 | 英雄编号 | 战斗图集 | 武器 |
| --- | --- | --- | --- |
| 回砂 | 3 | anim-8.webp | 青绿回旋镖 |
| 烬铃 | 4 | anim-9.webp | 燃烧药瓶 |
| 缝影 | 5 | anim-10.webp | 洋红弯镰 |

三张 RGBA WebP 均为 768 × 768，每格 192 × 192，站立基准为 (96, 175)。按行自左向右依次为四帧待机、四帧跑步、四帧攻击。最后一行依次为受击收身、后仰、跪倒、侧身伏地。

内置 ImageGen 以既有刺头精灵表为布局与光影参考，为每位新角色分别生成一张 16 帧原画。sources.json 记录各自的提示词、布局参考、原画 PNG 与对应大厅角色母版的位置。process.py 按 alpha 连通区域分出角色和投掷物，以每名英雄统一的缩放比和各动作的落脚点拼接，导出发布图集、64 像素预览与帧边界校验结果。

在当前目录运行 `uv run --with pillow --with numpy --with scipy process.py` 即可由原画重建。在 preview-64.png 中按从左到右依次查看回砂、烬铃和缝影，单帧显示尺寸为 64 × 64。
