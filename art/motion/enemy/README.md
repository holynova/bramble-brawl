# 敌人实战动作图集

每个物种有 16 帧，4 行 × 4 列，逐帧 192 × 192 像素。每行自左向右。第 1 行待机，第 2 行移动，第 3 行攻击，第 4 行受击两帧、退场两帧。坐标原点位于每格左上，地面角色脚底对齐 (96,175)。蝙蝠移动第 3 帧的翼尖会低于脚底。

参考文件是 `public/art/unit-{3,4,5}.webp`。生成原图在 `source-images` 中，文件名与角色对应关系见 `normalize.py`。原图是由三个参考分别编辑生成的整张图集。每个物种使用固定等比缩放。裁切仅提取该角色连通区域，并以透明阈值清除极浅的生成背景。蝙蝠缩放受最大翼展 180 像素约束。

运行 `uv run --no-project --with pillow --with numpy --with scipy python /tmp/bramble-motion-v110/enemy/normalize.py` 可重新输出 WebP、深色背景预览以及尺寸与动作变化检验文件 `quality.json`。运动数据是每对连续帧中可见像素最大 RGB 通道差超过 28 的面积比例。
